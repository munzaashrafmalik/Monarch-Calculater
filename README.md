# Monarch Calculator 👑

Monarch is a luxury-themed, web-based calculator designed with elegance and smoothness in mind. It's not just a calculator; it's an experience.

Features ✨

- Luxury Design: A sleek, obsidian and gold aesthetic.
- Smooth Animations: Fluid transitions and glow effects for a premium feel.
- Responsive: Optimized for both mobile and desktop screens.
- Easy to Use: Intuitive layout with essential functions.

Technologies Used 🛠️

- HTML5: Structuring the interface.
- CSS3: For the luxury styling, animations, and responsive layout.
- JavaScript: Handling the calculation logic and animations.

How to use 🚀

Simply visit the live link and start calculating!
https://munzaashrafmalik.github.io/Monarch-Calculater/
- Use the C button to clear your current entry.
- Use the AC button to reset everything.
- Enjoy the smooth animations as you calculate!
